# v0.5.1：一个模拟月确认恒纪元

本次唯一模拟规则调整：同一主星的束缚、引力优势和低扰动条件连续维持约一个模拟月（1/12显示年），即可确认为恒纪元。

- 轨道初值、四体积分、引力牢笼、主星判定阈值、退出滞后与文明参数沿用v0.5。
- 确认进度使用显示年份的实际增量，随时间倍速正确推进。暂停或年份不前进时不会继续累计确认时间。
- 面板以“模拟月”显示，默认1；JSON参数 `epochWindow` 仍以模拟年存储，默认 `1/12`。`epochTimebase: "years"` 标记新语义。
- 旧本机配置的默认值2迁移为1/12；其他明确自定义值保留其数值、按模拟年解释。窗口、灵敏度、韧性与轨道偏好不作额外迁移。
- 新的时间判定只影响纪元与由此产生的后续文明状态，不改变四体物理轨迹。不会保证任意Seed都满足单星束缚条件。

这是一项依据用户要求采用的约一月判定规则，不把精确数值冒称为小说的统一物理定律。

## 获取和部署

- 源码： https://github.com/BillOu0104/2
- 自动部署：`.github/workflows/pages.yml`，推送main后执行测试、构建、上传Pages制品并发布。
- 仓库首次使用Pages时，管理员须在 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。之后推送main即可自动更新。
- 本工程使用相对资源路径，可直接托管在仓库子路径 `/2/`。页面、Worker、贴图和设置文档均不需要远程模拟服务器。
- 原Sites项目标识不随GitHub源码分发，`.openai/hosting.json`仅保留可移植静态构建声明。

详细设置目录保持在 `docs/SETTINGS-GUIDE-v0.5.md`，构建产物包含同一份HTML和Markdown说明。

## 验证

88项模拟检查与6项实际浏览器检查通过。浏览器验证覆盖GitHub Pages的 `/2/` 子路径、Worker/贴图、一个月默认值迁移、以月显示/以年存储以及刷新后保留自定义值。

云端Node 22与本地Node 24对独立参考轨迹的最后几个二进制位存在浮点舍入差异（首次失败约7×10^-20）。参考轨迹测试使用1×10^-12的相对/绝对组合容差；同运行时的确定性/重放测试仍保持严格比较，物理算法未改。
