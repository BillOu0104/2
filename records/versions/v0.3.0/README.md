# v0.3.0 — 原著天象分层、文明复苏与原生8K

区分轨道纪元、天象、行星结构和文明状态；实现脱水、干仓、浸泡和同一文明延续。合并旋转环、慢速转动、紧凑日志与文字删减反馈，恢复原生8K背景并验证实际8K帧缓冲。
