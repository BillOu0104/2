# 下次合并修复的用户反馈

记录日期：2026-10-19（Asia/Shanghai）。这些项目原先按用户要求暂存；用户随后明确要求结合原著讲解一并修改，现已在 v0.3.0 实施并验证。

1. **旋转环按交互显示**：平时隐藏导航/旋转环，仅在鼠标按住并拖动旋转视角时显示；结束拖动后隐藏。自动旋转、鼠标跟随或惯性旋转不应单独使环持续显示。
2. **默认旋转速度**：降低没有鼠标操作时的基础自动旋转速度，使静置画面更舒缓。用户未指定具体倍数。
3. **时钟下方文明信息布局**：根据本次截图，收紧文明状态、存活时间和日志区域的行间距。文明日志条目使用一致的字体大小，靠逐渐淡出体现新旧，不靠字号变化。用户未指定具体像素值或淡出时长。
4. **文明适宜温度**：将适宜生存的温度范围调整为 **−20°C 到 40°C**，使判定更符合用户期望。实施时同步检查适宜度、恒纪元/生存判定、韧性恢复及界面提示，避免出现相互矛盾的阈值；不要继续把旧的宽温区默认当作适宜范围。用户未要求取消短时耐受或调整碰撞/大撕裂规则。
5. **去掉顶部文字**：移除左上角标题/标识文字和右上角宇宙编号、Seed 等文字，保留需要的信息在设置或档案中。
6. **去掉底部说明**：移除 YEARS 下方的说明句（“每一次重生，都是一次新的可能。”及英文版本），保留年份和 YEARS 本身。

验收：旋转环仅拖动时显示；默认自动旋转 0.35°/秒；日志统一 11px、45 秒渐隐，收紧中央间距；常态活动默认 −20～40°C；顶部两侧文字与 YEARS 下说明已删除。见 docs/qa/state-ui-8k-report.json。
