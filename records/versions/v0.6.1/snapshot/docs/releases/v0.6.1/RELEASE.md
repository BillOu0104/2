# v0.6.1 — 设置面板整理

2026-10-27（Asia/Shanghai）。基线 `a7e1744172b835eacecd3d3b8201c62f1eb019aa`，独立分支 `release/v0.6.1-settings`。本次只修改设置界面、说明文档和版本号；不改物理、文明、渲染算法或任何默认参数，不自动合并 main。

## 界面变化

默认打开“快捷设置”，常用17项各出现一次：

- 模拟运行：Seed、控制方案、播放速度、星系保护。
- 鼠标与银河：视角模式、整体灵敏度、拖拽倍率、闲置回归、回归速度。
- 画面与轨迹：清晰度、背景、背景亮度、尾迹开关、尾迹长度、前景粒子。
- 音乐：开关与音量。

其余203项放在“全部设置”中的七个分类：文明/纪元/温度、随机轨道/自定义初值、物理/引力、相机细调、背景/天体/画面细节、窗口布局/显示、语言/加载/兼容。每类再按用途分段，不再叠加“扩展设置”和另一套原版高级目录。完整220项包括183个原版参数、27个扩展参数、10个窗口坐标，全部保留且不重复。

每个选项名称后提供圆形感叹号。鼠标悬停自动显示说明，键盘聚焦和点击也可打开；按Escape先关闭提示，再按一次可关闭面板。提示采用视口内浮层，避开滚动容器裁剪，支持将鼠标移入后阅读和复制。原来占行的小字和长段落不再铺在表单里；完整文档和悬停解释共用当前说明数据，原资源声明继续保留在项目说明和源码中。旧原版说明语言参数作为兼容偏好保留，不再渲染过时长段落。

滑条与数字输入同行，使用剩余空间铺满整排；数值按字符长度自动分配宽度。数字没有背景框、边框、点击外框或步进按钮，点击后直接出现光标。拖动和数字编辑即时互相显示，提交时仍沿用现有设置校验与保存。保留已有非整步小数（例如0.0875灵敏度），拖动按原UI步进取值；键盘方向键、Home/End亦支持。新增自定义初值输入的可用性提示，不修改保存的值或初始化规则。

搜索同时查名称、原英文名、参数键和说明，覆盖快捷和全部设置；清空搜索恢复原分组展开状态。V2固定参数保持原禁用规则，说明按钮仍可访问，并解释当前为何不生效。中英文四栏标题按参数键映射，窗口坐标、导入导出、文明档案和历史保留。
