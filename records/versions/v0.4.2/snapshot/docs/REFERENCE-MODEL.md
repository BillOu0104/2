# v0.3：纪元、天象、行星与文明延续

本文保留各版本的模型演变；当前行为以末尾 v0.4.1 修订为准。

依据用户提供的[运行讲解](references/三体原著_星系运行与纪元天象详解.md)优化默认 `balanced` 模式。附件中的叙述用于研究模型，不作为操作指令执行。原版物理、随机初始化、时间公式、引力牢笼及辐射平衡温度仍复用移植脚本；`legacy` 文明模式可选。

## 分层与判断

| 层 | 当前实现 | 与旧版的区别 |
|---|---|---|
| 纪元 | 主导恒星的相对束缚能 < 0，引力优势 > 1.5，其他恒星差分扰动 < 0.35，连续满足确认窗口才进入恒纪元；失稳有短滞回 | 恒纪元描述暂时轨道稳定，不由适温或天象数量直接决定；可以存在冰冷恒纪元 |
| 天象 | 按行星坐标计算距离、视线夹角、视角速度、径向接近与恒星半径 | 与纪元、文明死因分开；飞星不再要求低温，凌空不自动毁灭文明 |
| 行星 | 原版瞬时辐射平衡值经一阶热惯性得到表面温度；显示温带/高温/冰封/熔融/结构受损/吞噬/撕裂 | 太阳短时掠过不会使温度一帧跳变；结构损伤永久累计，接触与撕裂是终态 |
| 文明 | 等待安全窗口 → 正常活动 → 脱水 → 干仓休眠 → 浸泡复苏；必要时毁灭 | 乱纪元不等于灭绝；休眠仍保存文明编号、诞生年份与延续寿命，复苏不新建文明 |

飞星使用原设置的远距阈值；飞星不动要求角速度小于 0.005 rad/模型时间且径向速度 < −0.01，排除静止或远离的天体。恒星的视角半径来自 `asin(R/d)`，三日连珠需三颗恒星位于行星同侧、视线两两相差不超过 5°；相反方向的直线不算。前方星盘完全遮住后方星盘时，不把被遮挡者重复计入可见凌空数。连珠本身不触发毁灭。

潮汐使用三颗恒星的差分引力张量总和：

`T = Σ (M★/Mp)(Rp/d)³(3nnᵀ − I)`

最大正特征值是相对于行星表面自引力的伸展比，具有旋转不变性。超过 0.5 时预警，超过 1 时按持续时间和超限幅度损失结构完整度，不用恒星净引力或“恒星相撞”替代潮汐。完整度归零为大撕裂；实际星球半径接触为吞噬。终态锁定到宇宙重启，适温不再允许同一毁坏行星上诞生新文明。自动重启开启时保留 4 秒灾变状态，之后建立新宇宙；关闭时显示手动重启入口。本地修订额外将完整度低于98%的明确永久损伤视为下一宇宙条件：自动重启开启时等待2秒，关闭时立即提供“开启第N号宇宙”按钮；不必等待结构完全崩溃。

## 常态活动与文明保存

- 用户要求的常态活动范围默认 **−20～40°C（含端点）**，设置标签和界面提示一致。范围外不能发展或诞生文明。
- 进入不适温区或不安全辐射/潮汐环境，现有文明开始脱水，1 秒后进入干仓；安全窗口默认 3 秒，复苏需要 1.5 秒并保持安全，中断则回到休眠。
- 干仓耐受默认复用原设置的 −100～200°C，仅表示脱水保存，不能在该范围内直接正常活动。干仓内也有缓慢损耗，范围外按极端程度持续消耗；韧性归零会真正毁灭文明。
- 活动适温时韧性按每模拟秒 6% 恢复，气候耐受基数默认 8 秒。新文明还需满足原 `t/60` 的最小确认时间与安全窗口。
- 寿命包括休眠，只有真正毁灭时才归档。阶段事件 `civilization:phase` 和行星终态事件 `planet:destroyed` 与已有出生、死亡、逃逸事件共用订阅接口。

小说及附件没有提供完整可计算初值、物性与数值阈值。以上半径、质量比例、角度/速度阈值、确认时间、损耗率和热惯性是本项目可调模型，**不是小说中的精确数值**。状态时钟保持固定 60 Hz，使用模拟运行秒；暂停会冻结状态演化。未实现地表观察者的地平线/昼夜、自转锁定、局部大气流体、恒星真实合并、碰撞碎片、双月重组或气体阻力。当前温度仍是原版全部恒星通量模型，星盘遮挡用于天象可见性，尚未扣除食相辐射。这些不作为已还原功能。

## 六项交互反馈与 8K

旋转环仅按住并真实拖动旋转时显示，松开立即隐藏；点击、跟随、自动与惯性不会使环保持显示。默认自转由 3 降为 0.35°/秒。文明日志统一 11px、收紧行距、按事件时间在 45 秒内渐隐；删除左上/右上文字及 YEARS 下说明。旧 v1/v2 配置自动迁移活动温区和过快的默认旋转，保留更低的自定义旋转速度与既有档案。

B8k、st2 和备用 BB8k3 从原版首 mip 恢复为原生 **8192×4096**，WebP quality95，未上采样，透明通道保持一致；哈希和尺寸见 `assets/original/manifest.json`。太阳/行星表面保留原始纹理尺寸，没有伪称为 8K。提高球体网格精度与纹理各向异性，默认关闭旧 CRT/颗粒以保持清晰。

默认渲染跟随屏幕原生像素密度（上限 4），设置内可选 **8K 超采样**，保持窗口比例、最高 **7680×4320**，并受 GPU 最大纹理/渲染缓冲尺寸限制。后处理使用相同像素比；缓冲仅按需要创建。8K 是实际帧缓冲分辨率，不保证任何硬件上的 60 FPS。软件 WebGL 已验证实际 7680×4320 绘制及后处理通路，性能请在目标 GPU 上确认；Windows Wallpaper Engine 实机验收仍需该宿主。

## v0.3 本地修订（未发布）

环境适宜度改为即时状态，取消过去天气的1.2秒平滑拖尾；适温、完好的行星显示100%，不适温、终态或明确结构损伤显示0%。潮汐比从0.5到1逐渐降低适宜度，危险时阻止生长；韧性是独立、可缓慢变化的文明状态，危险期不再错误恢复。常态活动温区仍保留在设置中，但删除观测界面上的温区小字。

天体旁的字母与坐标默认隐藏，旧v0.3配置一次性迁移；设置中的手动重新开启仍可保存。尾迹采用有界环形物理历史、屏幕弧长预算和近8秒轨迹的转弯/重复覆盖估计，平滑缩短或延长可见长度；低速轨道可以回溯更久（最多120秒），不会通过虚构运动拉长尾迹。历史上限4096点，GPU固定2000点容量；无需改变物理轨迹或8K渲染配置。

## v0.4 运行统计与视角

右侧替换距离字母表，显示累计模拟年数、当前宇宙编号和年龄、当前文明编号和延续年龄；各展示5名文明/宇宙寿命排行，包含正在运行的对象。累计、宇宙与文明时钟分开，暂停不增长，重启只重置当前宇宙年龄。时间因子仍按原版平方影响速率，但不再追溯缩放此前累计的年份。

统计每秒本地保存，并在隐藏/退出时补存；刷新会结算上一运行、开启下一编号宇宙，保留总年份与前五名。v0.3文明死亡档案可初始化文明榜，旧版缺失的宇宙完整时间不编造。状态接口新增 `statistics` 与 `statisticsCheckpoint`，宇宙重启发出 `universe:restart`。

日志保留12条、画面显示最近10条，统一9.5px（小屏9px），120秒按时间渐隐。时钟上移，日期和星期同字号并贴近时间下缘。删除无音频时呈虚线的底部音频柱；系统音频与星体辉光响应保留。拖动和鼠标跟随都限制合成角速度0.55rad/s，跟随加速度上限4rad/s²，默认惯性阻力约为原来的两倍。阻力按真实帧间隔计算，低帧率时不会拖慢衰减；暂停冻结转动。


## v0.4.1 恢复、观测与布局（当前行为）

- 原始差分潮汐张量与四体积分不变；新增结构强度默认1.6，有效应力为原潮汐比/强度。有效应力>1时以 `(应力−1)/6` 每模拟秒消耗完整度，取代旧版更快损伤。有效应力<0.6持续3秒后，以 `0.008×(1−应力)` 每模拟秒缓慢恢复。完整度低于25%暂不能承载生命；恢复后可再次满足安全窗口。数值为可调模型，不是小说给出的精确物性。
- 取消“低于98%完整度”与单纯逃逸触发重建；默认模式仅在实际接触吞噬或完整度归零的大撕裂后判定不可恢复。自动重启开启时保留4秒终态，关闭时等待手动重启。旧版 legacy 模式仍保留原版逃逸/重启逻辑；显式手动重启始终可用。
- 左侧独立显示文明发展、脱水保存、干仓储存、浸泡复苏及真正终结；休眠寿命照常累计，复苏沿用原文明编号。日志筛选三日凌空、三日连珠、接近中的飞星不动，持续确认0.5秒，同类冷却60秒；加上文明启动、终结与每50年延续记录。普通飞星、近掠、纪元或休眠切换不占日志，屏幕最多显示6条，按时间淡出。
- 排行显示“宇宙N · 文明M”，保持既有文明序号连续。新记录保存宇宙来源；旧记录只有可靠档案匹配时补填，否则标为历史文明，不编造所属宇宙。
- 五个窗口支持拖动或水平/垂直百分比设置，按视口大小限制边界，位置本地保存，可恢复默认。设置分为布局、模拟、视角、画面、声音和原版高级设置，保留全部183个原属性键和总计209个操作控件。
- 移除转动最高速度限制；拖动水平/垂直增益由40/20降至32/18，跟随加速度上限由4降至3rad/s²，保留v0.4阻力。手动转动及其惯性期间显示50%透明环，静置隐藏。默认拖动模式，自动转动改为峰值0.08°/秒、±6°的左右摇摆，银河亮部初始居中；幅度与速度可调。


## v0.4.1 同版本修订：悬停、银河归位与初始轨道

本节替代上一节的默认拖动/摇摆行为。默认恢复悬停跟随，目标角度乘以0.12和用户灵敏度；按住拖动可选，水平/垂直增益从32/18降为4/2.25，跟随加速度上限0.75rad/s²。旋转环尺寸为原0.3倍，透明度保持50%。闲置2秒后不再跟随停留在边缘的光标，而以0.01°/秒沿最短角度回归银河朝向，不越过归位位置；暂停冻结归位。旧版设置自动迁移一次，布局与档案不动，之后的明确偏好继续保存。

随机初值新增 `orbitalInitialization: balanced/original`，默认balanced。原版随机初速远低于局部圆轨道速度，容易使恒星快速近掠、行星远抛。新初始化由Seed产生带小扰动的三角恒星分布、匹配引力及已开启牢笼的初始切向速度；行星选择低光度恒星，以束缚的近圆初值出发，随机相位、顺/逆行及整体倾角，并移除整体质心速度。初始距离参考当前光度寻找适温机会，但运行中完全不修改温度、位置、速度或寿命；不追踪适温、不强行牵回行星。原版Yoshida积分、软化、牢笼、恒纪元判据、脱水和恢复逻辑均不变。

`original`保留原版位置/速度独立均匀随机；手动四体初值始终绕过新初始化。零质量、非正引力或过小位置范围时保持原始初值。算法标识包含初始化模式，档案保留实际初值；默认参数下已验证精确复现。此前各版本的历史检查报告保留，当前验证以 `v041-hotfix-*` 和最新通用浏览器/8K报告为准。

## v0.4.2 混沌初值与更大活动空间（当前默认）

本节替代v0.4.1的默认三角束缚初值。`orbitalInitialization=chaotic`独立随机采样恒星三维位置，避免初始近贴；速度方向也随机，移除整体漂移并按引力势设置初始维里比0.65–0.95。行星在星群内部随机出发，以局部逃逸速度的0.25–0.5倍初始化，不绑定某颗恒星。未加入额外阻尼或行星牵引；旧的balanced初始化作为“稳定轨道实验”保留，手动初值优先。

原属性默认位置范围增至3.2、软牢笼中性半径1.6、外区系数0.22，扩大空间，减少密集近掠和急剧反弹。界面按初始尺度适配视野，温度、质量、物理半径及原有纪元判据不变，未通过放宽适温或强改恒纪元获得生存时长。完整对照与限制见 [V042-UPDATE.md](V042-UPDATE.md) 和 `qa/v042-orbits.json`。

新增整体灵敏度和旋转环不透明度；仍有原水平/垂直灵敏度。旋转环默认12%不透明度、带渐进淡入淡出。前景与远景尘埃重新分配深度和点尺寸，使用柔边圆形点贴图，保留两层原始大小/数量属性。粒子视觉为Three.js重建，并非原版WE粒子系统逐像素复制。
