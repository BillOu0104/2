# v0.4.2

恢复默认混沌系统与前景粒子的存在感，并让视角灵敏度和旋转环透明程度可调。

- “全部设置 → 视角与银河 → 整体视角灵敏度”控制悬停和拖动的共同倍率，默认0.12、范围0–2；水平/垂直倍率仍可分别调整。悬停、不限最高速度和极慢回归银河保留。
- 旋转环保留0.3倍尺寸，默认不透明度降至12%，可调0–50%。出现按0.18秒时间常数淡入，结束按0.55秒时间常数淡出；不透明度为0时完全隐藏。时间常数为渐近缓动，并非硬切换时长。
- 默认初始化为不规则三维位置与随机方向的速度，不再采用三角恒星分布或绑定某颗恒星的近圆行星轨道。随机恒星速度按局部引力势设置初始维里比0.65–0.95，避免原版过低初速直接坍缩。行星初速低于局部逃逸速度，后续完全由原版四体解算和牢笼推进，不做拖回、传送或永久稳定处理。
- 默认初始位置范围2→3.2，软牢笼中性区半径0.2→1.6，外区约束系数0.5→0.22，硬牢笼备用边界2.1→4。扩大可活动区域，并减弱外区的急剧反弹；硬/软模式开关仍由原设置决定。画面按尺度自动适配，原版随机、稳定实验轨道与手动初值保留可选。迁移只更新旧默认值，保留明确的自定义参数、窗口布局与档案。
- 前景/远景尘埃改为两个具有深度和柔边圆形贴图的粒子层，前景更靠近镜头、点尺寸更明显，具有缓慢漂浮和视差。两层原始数量和大小控制保留，数量在原完整范围内生效；粒子设置移到“画面与轨迹”。没有额外在线素材或外部依赖。

16组相同Seed各运行200个模拟年，与原版默认随机配置对照：行星位于两倍恒星外缘以外的平均时间占比约25.5%→11.5%；相对恒星的机械能为正且距离超过1.5倍外缘的占比约21.9%→6.4%。新配置中完整行星处于恒纪元的时间约9.9%，仍以乱纪元为主。微小速度扰动1e-7在有限运行中造成约0.51模型单位的恒星位置均方根分离，保留明显的敏感依赖。

上述时间占比按各Seed中行星仍完整的时间计算，衡量有限运行中的远抛状态，不等于永久逃逸概率；各Seed结果仍有差异，没有寿命或恒纪元保底。报告为 `docs/qa/v042-orbits.json`。

验证包括72项模拟检查、实际滑块改变转幅、旋转环淡入淡出、粒子单层开/关像素比较、全部211项控件及WE回调、尾迹绘制，以及开启粒子的实际7680×4320帧缓冲和后处理。当前环境没有Windows Wallpaper Engine，未做该宿主实机验收；软件WebGL检查不作为目标显卡帧率承诺。
