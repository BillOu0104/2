# v0.5.2 物理修复验收

本版修复了近距离引力异常，并移植研究中验证过的随机三星初始化。**新实验中，千年平均受限寿命由129.68年提高到235.63年，恒纪元占比由3.01%提高到20.70%；但1000年末仅5/128颗行星存活，10000年末0/128。** 改善有限，不代表获得稳定或普遍长寿的混沌三星。

开发分支：`fix/v0.5.2-newtonian`；基线：`c7a53a01def5f9d60389ee20ec0f8bac5210ed69`（v0.5.1）。版本号0.5.2，供验收；不合并或部署到正式main。

## 修改内容

- 默认引力为 `aᵢ = G mⱼ (rⱼ−rᵢ)/|rⱼ−rᵢ|³`。每对天体同时获得等大反向的动量增量。删除默认路径中旧的近距离增强、分段跳变和距离下限伪装。旧模型保留为 `legacy` 兼容选项。
- 默认无软化，势能为 `−Gmᵢmⱼ/r`。可选Plummer软化使用同一个ε：势能 `−Gmᵢmⱼ/√(r²+ε²)`，加速度分母 `(r²+ε²)^(3/2)`；没有分段边界。软化不是默认改善手段。
- 保留Yoshida四阶组合，采用完整精度系数。每个子步 `h≤min(hmax, η√(r³/G(mᵢ+mⱼ)), ηr/vrel)`，遍历全部有效天体对；默认η=.0075、hmax=.00075。固定步长方法的四阶精度保留，**自适应之后不声称全局严格辛性**。
- 每帧推进原默认对应的.0075求解时间，近遇增加子步，不以少算时间维持轨道。默认每显示年推进.45求解时间；realtime模式推进预算不同，必须另行比较。时间倍率的原有平方关系保留。
- 子步最低尺度1e−10、单次advance最多200000子步；奇点、非有限值或预算耗尽会明确报错/暂停。失败子步回滚到最后有效状态，不阻尼速度、不拉回行星、不改轨道。正常时钟尾部的微小余量允许算完，不误报近遇精度不足。
- 在已接受子步的起终相对线段检测球面接触，避免把Yoshida负子阶段当成真实路径。行星接触产生吞噬终态；恒星接触发事件并标记点质量模型受限，不虚构碰撞后的合并/反弹轨道。
- 状态/API及“项目说明”提供质心系总能量、总动量、角动量、误差、累计子步、求解时间、接触及数值错误。启用牢笼时明确标为非孤立系统，不能用孤立牛顿总能守恒判断。误差按状态输出采样，不能视为所有子步的严格上界。

## 默认初始化

保留v0.5.1不规则三维随机三星位置和随机速度方向。只去掉三星质心漂移，并缩放速度，使三星 `Q=2K/|U|=1`。不强制旋转角动量，不构造层级双星或8字轨道。

宿主预先固定为数组第3颗恒星，取它与其他恒星最近距离D；行星半径为.12D。行星径向由旧随机行星位置确定，投影到恒星总角动量垂直平面，切向与三星总角动量逆向。相对速度为 `√(G(M宿主+m行星)/r)`，宿主速度叠加及质量反冲同时处理，最后四体一起去质心漂移。Q=1指加入行星反冲前的三星，反冲后会有千分量级的小变化；不能为追求精确Q再次改动已构造的相对圆轨道。

只检查即时几何和合法数值，不运行未来轨迹、不筛长寿Seed，不使用已知成功Seed。默认随机模式与研究候选在16个预定种子上逐分量一致。若用户把半径/尺度调到初始重叠，报配置错误，不偷偷改变半径或换种子。关闭天体（质量0）、非正G或极小随机范围时无法定义这一四体宿主方案，保留原始初始化并在元数据说明回退原因；该回退没有参与默认基准。

自定义初值永远优先。完整导入数组独立保存，避免新轨道速度被旧滑块范围截断；改界面或粒子设置不会重新生成这些初值。

## 本次实验：128个新种子、匹配三组

全新队列 `V052-ACCEPTANCE-0` 至 `V052-ACCEPTANCE-127`，每组同样128个种子、1000显示年、牢笼关闭、原G/质量/半径/逃逸距离/文明/纪元规则。未挑选或丢弃失败种子，三组数值中断均为0。

### 统计口径没有放宽

沿用报告：行星第一次被WorldState判为吞噬/撕裂，或行星到**四体质心**距离超过6，记为首次目标损失。寿命在1000年处截断。联合存活额外要求恒星没有越过原边界、没有名义半径之和接触。

越界不自动等同真正逃逸。只有越界、相对三星质心的瞬时比能为正且向外运动，才归入上表的弹射代理；其余单列，不能冒称已证明渐近逃逸。恒星越界另计，不代替行星越界。

恒纪元占比=首次行星损失之前的恒纪元帧数/**完整观察窗帧数**，损失后贡献0。没有用“仅幸存阶段”缩小分母。事件损失吸收后停止积分，所有这些主要端点与继续跑至期末等价；因此raw的finalBodies仅表示停止时状态，不能当作期末坐标。compactNonhierFraction/hierFraction等附加轨迹字段也只覆盖实际积分段，本版不拿它们与研究全程占比混比。数值错误独立标记，不算作物理死亡；本次640次运行没有此类删失。

基准按研究的60Hz WorldState采样和名义恒星接触口径计算，不把新增的子步接触事件悄悄混进主表。实际壁纸还会检测帧间接触，所以个别吞噬会更早发生。能量、角动量误差仅取首次恒星接触与首次行星损失之前；接触后的点质量延拓不能用来证明真实恒星行为。

### 收敛与长窗口

- 同128个Seed、新初始化，hmax=.000375、η=.00375全量复算：平均235.62799年，行星仍5/128，联合仍3/128，恒纪元20.70448%。首次损失时刻平均绝对差.00156年，最大.08333年。最大有效能量误差降为1.16e−9。没有以挑选一致的Seed通过验证。
- 同128个Seed延长到10000年：行星0/128，联合0/128；平均受限寿命291.78年，全窗恒纪元2.62465%。这反映真实长窗口失败，未用于反过来选择初始化。
- 独立SciPy DOP853：另一个预定队列前4个种子，4.5求解时间，独立实现牛顿力，rtol=1e−12/1e−13、atol=1e−14/1e−15。默认内核状态与更精细参考最大差2.87e−9；h、h/2、h/4固定步长复核中，误差高于舍入平台的案例呈约16倍收敛。其余案例已接近1e−12量级，不要求舍入误差继续按16倍下降。参考轨迹的密采样表面间隙均为正。

- `newproperty60`牢笼及全部软/硬牢笼参数继续可调。新默认及旧启动配置升级会关闭牢笼。启用后即不是本表的纯牛顿实验；牢笼能量不包含在孤立系统诊断内。

## 未解决问题

随机非层级三星仍容易衰变、形成暂时双星并弹射第三星或行星；Q=1只修正初始能量分配，不保证稳定。行星贴近宿主带来更高恒纪元，也增加吞噬/潮汐损失。不能通过改阈值、扩大文明耐受或牢笼力掩盖这些结果。

没有实现恒星接触后的流体合并、真实潮汐耗散、相对论或质量—半径—光度的自洽恒星演化；现有温度/文明仍是壁纸抽象模型。长期混沌轨迹的逐点精确预测没有保证，有限时守恒与步长收敛不能消除这一限制。
