# v0.4.1

恢复左侧完整文明观测，优化可恢复行星和静置视角，并允许重新安排画面中的信息窗口。

- 左侧文明阶段独立显示发展、脱水、干仓储存、浸泡复苏和终结；休眠与复苏延续同一个文明。
- 全部设置分为布局与窗口、模拟与文明、视角与银河、画面与轨迹、声音、原版高级设置。展开“布局与窗口”，点击“拖动调整窗口”，拖动左侧、右侧、时钟、中央日志或底部年份，再点“完成布局”。也可直接设置各窗口水平/垂直位置；本地保存，支持恢复默认。
- 中央日志保留少数罕见天象和文明启动、终结及每50年寿命记录，最多显示6条并淡出。普通飞星、巨日和状态切换不刷屏。
- 新文明记录和排行使用“宇宙N · 文明M”。保留既有连续文明编号；来源不明的旧榜项显示“历史文明”，能匹配旧档案时补回宇宙编号。
- 取消转动速度上限，稍降拖动增益与跟随加速度，保留阻力；手动转动和惯性期间显示50%透明的可视化环。
- 行星默认结构强度提高到1.6，降低潮汐损伤速度，低应力持续3秒后缓慢恢复。只要尚可恢复，受损或逃逸都不会自动重建宇宙；吞噬或完整度归零才进入不可逆终态。手动重建与原版legacy模式仍可选。
- 默认镜头朝向原版银河全景中测得的明亮区域，静置以峰值0.08°/秒在±6°内左右摇摆，不再持续转离银河。原生8K背景、可选8K帧缓冲与自适应尾迹保留。

上述强度、损伤与恢复参数为本项目模型，不代表小说提供了精确物性。具体公式与版本演变见 [REFERENCE-MODEL.md](REFERENCE-MODEL.md)。

验证：62项模拟检查、17项通用浏览器检查，以及本版窗口/文明/旋转专项、尾迹像素对比和实际7680×4320帧缓冲及后处理检查。结果见 `docs/qa/v041-simulation-report.txt`、`v041-browser-report.json`、`browser-report.json`、`tail-render-report.json` 和 `state-ui-8k-report.json`。专项报告明确标注使用受控快照的界面阶段；物理、恢复和休眠在真实模拟中单独验证。当前环境没有Windows Wallpaper Engine，未做该宿主实机验收；软件WebGL的8K通过不代表目标GPU的帧率。
