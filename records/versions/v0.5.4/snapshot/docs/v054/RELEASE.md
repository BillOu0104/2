# v0.5.4：松手回弹、完全重置与逃逸重建

基线：v0.5.3 源实现 `292d21d93e90ae212a41f828ea454337582dbf2b`；本次独立分支 `fix/v0.5.4`。正式 main 不覆盖，沿用原私有网页预览。

## 1. 为什么松开拖动会反弹

v0.5.3 的松手处理把当时视角作为新的悬停目标，但视角仍带有拖动惯性。下一帧切回悬停跟随时，惯性先让视角越过目标，随后跟随弹簧又将它拉回来，所以有一次短小的反向转动。这和银河归位速度本身是两个问题。

现在松手后先按原阻尼自然滑行，不调用悬停弹簧。真实的鼠标移动恢复时，以已滑行到的位置衔接悬停跟随，保留拖动和悬停两种操作。松手、取消拖动和丢失指针捕获均适用；重复的结束事件不重复重建基准。

松手也重新开始闲置计时：即使按住鼠标停了两秒，松手时也不会马上向银河转回。连续闲置两秒后才进入原有银河归位逻辑。默认总角速度由 **0.003 调到 0.006°/秒**，保持单独可调；固定视角不受影响。回中独立接管惯性、不越过目标、旋转环淡入淡出和原有灵敏度参数保留。

`galaxyReturnRevision=2` 标记本次一次性默认迁移。识别旧默认 0.003（及更早的默认 0.01），其余明确自定义速度保留。旧配置中和旧默认恰好相等的手动值无法区分，升级后可重新设回 0.003。

## 2. 完全重置历史

入口：右下角齿轮 → **文明档案 → 完全重置历史**。点击后明确确认一次，取消不清除数据。

确认后清空当前浏览器/当前站点的文明死亡档案、宇宙/文明排行榜、累计年数、当前运行与日志，重新从宇宙1、文明1开始计数。保留全部设置、Seed、窗口位置、自定义初值、自定义背景和暂停状态。保留 Seed 意味着重置后的第1号宇宙仍可复现同一组初值。

普通“重启”仍保存上一个宇宙并进入下一个编号；“恢复默认”仍只恢复设置并保留历史。按钮不会修改 GitHub 中的版本记录，也不影响其他浏览器的档案。

实现先暂停接收旧模拟状态，使用 IndexedDB 独立历史表事务等待此前写入完成再清空，并替换 Worker 与事件序号，防止旧消息补写历史。清理完成后重新保存空的新运行检查点。背景 assets 表不清空。跨 IndexedDB/localStorage 的清理用待完成标记保护；中途刷新会先完成清理，再启动模拟。若存储不可写，会明确报错；清空已开始时暂停模拟，保留标记供重试，不伪报成功。浏览器拒绝 localStorage 时，普通模拟仍可启动。

## 3. 明确分离后的逃逸重建

不加力、不拉回、不修改轨道。新增 `EscapeState` 只读取真实坐标、速度和质量。默认现代文明模式在原有自动重建开关 `autorestart` 下增加如下条件：

1. 引力牢笼关闭，模型为牛顿或 Plummer。
2. 至少一个天体已经超过**原有逃逸距离** `newproperty13`，本版不改变该距离。
3. 将四体划分为两个星群，检查全部7种不同划分；两群距离大于各群质心包络半径之和的4倍，避免在复杂近遇时轻率判断。
4. 两群沿相对径向向外分离。
5. 两群相对运动的比轨道能量为正，且大于相互引力势能绝对值的10%，排除接近抛物线的敏感边界。势能复用引擎的 `pairPotential`，Plummer 使用同一软化参数；内部各自的轨道能量不混入群间能量。
6. 同一划分连续满足 **3显示年**。任一条件中断，计时清零；不跨多个短暂事件拼接累计。

因此既能处理独立行星逃逸，也能处理恒星分裂、宿主携行星整体离开其余三星系统的情形。确认后正常归档文明和宇宙，下一帧生成下一号宇宙，累计年数保持连续。关闭自动重建则只通知并显示手动入口；重新开启后允许自动重建。开启牢笼时不使用此确认，因为牢笼可能将天体拉回。

仍有束缚的远日点、向内回落、靠近系统中心的一次高速度、短暂正能量或文明死亡不会单独触发该重建。行星吞噬/不可逆撕毁保留既有重建路径；legacy 原版文明模式仍采用其原始逃逸路径。

**限制：有限时间内的四体轨迹不能仅凭一帧正能量证明未来绝对逃逸。** 本版使用几何隔离、能量余量和持续确认的保守运行规则，并不声称数学上证明了任意混沌系统的未来。临界或仍高度纠缠的分离会继续观察，可能延后重置。开启此自动重建会改变宇宙寿命/文明记录的终止时机；不能拿开启重建后的统计冒充物理存活率提高。
