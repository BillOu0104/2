# v0.4.1

当前为v0.4.1修订发布，版本号保持不变。恢复左侧完整文明观测，优化初始轨道和悬停视角，并允许重新安排信息窗口。

- 左侧文明阶段独立显示发展、脱水、干仓储存、浸泡复苏和终结；休眠与复苏延续同一个文明。
- 全部设置分为布局与窗口、模拟与文明、视角与银河、画面与轨迹、声音、原版高级设置。展开“布局与窗口”，点击“拖动调整窗口”，拖动左侧、右侧、时钟、中央日志或底部年份，再点“完成布局”。也可直接设置各窗口水平/垂直位置；本地保存，支持恢复默认。
- 中央日志保留少数罕见天象和文明启动、终结及每50年寿命记录，最多显示6条并淡出。普通飞星、巨日和状态切换不刷屏。
- 新文明记录和排行使用“宇宙N · 文明M”。保留既有连续文明编号；来源不明的旧榜项显示“历史文明”，能匹配旧档案时补回宇宙编号。
- 默认恢复不用按住鼠标的悬停跟随；悬停角度为旧范围的0.12倍，拖动增益降为旧版的1/8，跟随加速度上限0.75rad/s²。保留阻力与无最高速度限制。转动环缩至原尺寸0.3倍，保持50%透明，手动运动结束后隐藏。
- 行星默认结构强度提高到1.6，降低潮汐损伤速度，低应力持续3秒后缓慢恢复。只要尚可恢复，受损或逃逸都不会自动重建宇宙；吞噬或完整度归零才进入不可逆终态。手动重建与原版legacy模式仍可选。
- 默认镜头朝向银河亮部；不再来回摇摆。停止操作2秒后沿最短方向，以0.01°/秒缓慢归位，到达后停止。原生8K背景、可选8K帧缓冲与自适应尾迹保留。
- 默认随机初始化改为带扰动的束缚轨道：恒星初速匹配引力与现有牢笼的径向约束，行星围绕低光度恒星运动，并进出星群内部。所有后续运动、温度和纪元判据不变，不设文明寿命保底；原版完全随机及手动初值仍可选。旧设置自动迁移交互默认值，窗口位置与档案保留。

上述强度、损伤与恢复参数为本项目模型，不代表小说提供了精确物性。具体公式与版本演变见 [REFERENCE-MODEL.md](REFERENCE-MODEL.md)。

验证：67项模拟检查、17项通用浏览器检查、窗口/文明/旋转专项和本次悬停/归位专项，以及尾迹像素对比和实际7680×4320帧缓冲及后处理检查。修订模拟报告为 `docs/qa/v041-hotfix-simulation.txt`，轨道对比为 `v041-hotfix-orbits.json`，鼠标专项为 `v041-hotfix-browser.json`；其余报告保存在同目录。阶段/排行界面截图中的受控快照在对应报告明确标注，悬停与归位使用真实鼠标事件验证。

同样8组种子各运行100个模拟年，原版随机/新束缚初始轨道的完整行星恒纪元占总运行时间分别约1.8%/85.6%，发展时间约0.14%/38.7%；连续发展超过1年的种子为0/8和8/8。另24组新种子各运行400年，均出现连续超过1年的发展期；这些是具体默认参数样本，并不保证所有种子与自定义参数具有同样表现。

当前环境没有Windows Wallpaper Engine，未做该宿主实机验收；软件WebGL的8K通过不代表目标GPU的帧率。
