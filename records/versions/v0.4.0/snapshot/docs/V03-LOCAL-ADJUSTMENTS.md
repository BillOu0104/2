# v0.3 本地修订，暂不发布

用户要求：在 v0.3 内修改，不发布 v0.4。本次保留版本号0.3.0，不调用站点发布、不推送托管源码，也不覆盖原发布包。

- 天体旁的 α/β/γ、符号与坐标默认隐藏；已有v0.3设置自动迁移一次。仍可从完整设置主动重新打开标签。
- 适宜度显示当前环境，避免22.6°C时仍滞留在旧天气的60%。温区仍为−20～40°C；完好、无潮汐危险的适温行星显示100%，明确结构受损或终态为0%，潮汐风险会降低分值。文明韧性独立计算，危险环境中不再恢复。
- 行星完整度低于98%即认为已有明确结构损伤；自动重启开启时2秒后进入下一编号宇宙，关闭时立即提供手动入口。新宇宙会清除旧行星损伤与尾迹，死亡归档与损伤事件不重复触发。完全崩溃或吞噬仍保留原有终态规则。
- 删除画面中的“活动适温：−20～40°C”小字；阈值仍可在设置中修改。
- 尾迹由固定帧数改为自适应屏幕长度：转弯、重叠和快速运动时缩短并降低亮度；单调缓慢运动保留更久的真实历史。调整连续平滑、不清空历史；最多4096个历史点/120秒，每条GPU最多1999个线段。

验证：原有30项模拟测试与新增10项修订测试通过；常规浏览器17项检查、此次专项6项检查通过，无JavaScript错误。浏览器专项通过真实Worker验证受损行星在终态前显示0%并可开启第2号宇宙，通过受控消息验证真实GPU尾迹：平缓轨迹约485～492px、36.6秒历史；复杂轨迹在平滑收缩过程中约150～180px。尾迹开关同帧像素对比通过。报告见 `docs/qa/v03-local-report.json`、`browser-report.json`、`tail-render-report.json`。

8K资源和渲染选项保留；此修订未重新进行8K帧率测试。当前环境没有Windows Wallpaper Engine，实机验收限制仍保留。
