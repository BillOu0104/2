# 位置与速度消融

32连续新种子、400显示年、相同三星初值和原始Q分布，全部精确牛顿严格自适应。

|行星处理|幸存|受限平均寿命|全窗恒纪元|
|---|---:|---:|---:|
|原始位置和速度|8/32|182.12|12.9%|
|原位置，仅改成宿主相对圆轨道速度|3/32|155.71|7.6%|
|仅放到.12D，保留原速度|1/32|35.19|8.5%|
|.12D位置与逆行圆轨道速度一起修复|7/32|187.99|36.4%|

相对初始束缚能并不足够：只放近而不补充角动量导致快速近心损失；仅补速度但保留受多星强扰动的位置也无普遍改善。
正确位置+速度在该独立消融组中提高恒纪元，但生存率并未高于随机组；因此不能把“圆轨道”宣传为独立解决长期生存的充分条件。
研究再次反驳单因素直觉。主候选还包含恒星Q控制，须由冻结的128种子确认集评价。

首次行星损失或恒星接触前，四组能量误差最大约1.2e-8；结果不是靠粗积分将行星隐藏。
