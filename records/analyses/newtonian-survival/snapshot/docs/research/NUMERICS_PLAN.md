# 数值误差与散射诊断的事前控制

阶段1原分段力能量误差中位数约2%，精确牛顿最差种子约3e-5；独立DOP853验证表明近遇的状态误差需要逐步收敛。
因此在探索结果之外，独立执行固定初值、相同物理窗口的步长/算法比较。
连续种子 NUMERICS-0..23，无先验寿命挑选。窗口400显示年。

- 原随机行星：原力默认/四分之一dt；牛顿固定默认/半dt；牛顿自适应eta=.03/.0075。
- Q1.4主星圆轨道：牛顿固定默认；自适应eta=.03/.015/.0075；独立二阶velocity-Verlet用更小最大步长。
- 记录模型对应能量，而非仅Newton能量；牛顿与原力的物理差异不能靠减小dt消除。
- 混沌轨迹长期不能逐点严格相同；比较守恒误差、事件类型和种子级统计，不强行要求同一逃逸时刻。
- 算法不是为了增加“可见存活率”，严禁改时间推进速度和判定定义。

新的阶段1事实：32个原始随机行星初始时均对至少一颗恒星具有负相对能量，因此“普遍初始未束缚”已被这组数据否定。
更精确假设是缺乏近圆轨道及扰动隔离：最近主星参考系初始偏心率中位数.818，18/32大于.8；主星轨道修复后为0。
