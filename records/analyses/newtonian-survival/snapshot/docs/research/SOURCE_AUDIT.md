# 最新运行源码审计

基线 SHA：c7a53a01def5f9d60389ee20ec0f8bac5210ed69；远程 main 已实查一致。

- 浏览器 `src/main.js` -> `src/simulation-worker.js` -> `src/simulation.js`，Node 可直接用同一个 Simulation。
- `src/settings.js` 默认 chaotic 初始化、reference 模式，实际 propertySchema 开启牢笼；因此历史带牢笼 QA 不能证明本目标。
- `src/orbital-initialization.js:prepareChaoticOrbits`：三星在范围 3.2 的三维盒中采样，初始间距 >.3 倍范围；去恒星速度质心后归一化 Q=2K/|U| 为 .65–.95。行星位置独立，速度为系统总势瞬时逃逸速的 .25–.5 倍，全局随机方向，未加宿主速度。最后只去四体共同速度。
- `prepareBalancedOrbits`：近等边同向旋转三星 + 主星束缚行星，不能直接代表任意非层级混沌系统。初始化速度中还可含牢笼项，因此研究始终先关闭牢笼。
- `src/legacy/008.js:computeAcceleration`：r<=eps 为线性力；eps<r<k eps 为 [alpha+beta*r/eps] GM/r²，beta=3/(k-1)，alpha=1-beta；r>=k eps 才是 GM/r²。k=2.8 时边界左侧为 4 倍牛顿力，右侧为 1 倍。它不是 Plummer 软化。分段连续势能可定义，但加速度不连续，精确牛顿能量不应被误当作该力的守恒量。
- 默认 G=1.3275440274585598e-8，恒星质量各 5e6，行星 5000；空间单位源自 1e12m，显示温度另用距离倍数7，整体参数不是完整天体物理标定。
- 积分器 Yoshida 四阶 drift/kick（三次力评估，含负系数），默认 dt=.00075、每参考帧最多10步。首次初始化帧无物理推进，随后每显示年 .45 求解器时间。直接减少产品步长而不增加步数会同时减慢物理，不能当数值改善。
- `shared.tj` 是任意天体离四体质心 >6，并非行星专属或正能逃逸。balanced 文明模式并未因此直接终结行星，而主要依据 WorldState 的吞噬/结构终态；因此分别记录这些口径。
- `src/world-state.js`：恒纪元要求主星相对二体能量<0、力优势>1.5、其他星潮汐扰动<.35，确认1/12显示年；切回乱纪元有.5秒迟滞。并非仅温度。
- 吞噬取恒星可呼吸半径+行星半径；行星半径.01、三星半径.03/.023/.016。潮汐为总张量最大特征值/行星自引力，强度默认1.6；过量应力累积破坏，可恢复轻伤。恒星之间无碰撞合并或终止，研究另记接触时间以识别点质量模型局限。
- `src/legacy/079.js` 温度包含雪反照率反馈、+/-10K正弦、温度截断及距离倍数，不适合作真实气候生存证明。研究主指标为轨道/结构存活与原恒纪元，另记默认适温率。
- 产品保存种子、初值、文明历史和统计 checkpoint；并无完整积分器状态导入接口。研究按种子粒度落盘，任务中断最多重跑当前一条，不能声称任意步续算已完成。
