# 下一假设：恒星轨道族，而非只改维里比

依据：前两阶段改善了早期恒纪元，但400年联合存活仍有限；独立16种子微扰诊断在500年仅1个候选联合幸存。
因此当前证据不足以把任意随机三星束缚系统当作长寿架构，需要明确检验几何构型的边界。

增加已知等质量 figure-eight 周期解作为非层级但**非混沌**对照；它不能直接算目标达成。
对该初值每个坐标/速度分量加入事前固定幅度的独立随机扰动(.1%、1%、5%，相对基准位置/速度尺度)，不模拟挑选种子。
若扰动族延长存活，再用影子轨迹与更长窗口区分“接近规则轨道”与“长期混沌且完整”。
固定质量、物理半径、逃逸阈值6、恒纪元定义；行星r=.12D、固定z平面负向圆轨道。不把总角动量近0时的方向称作恒星整体逆行。
新种子GEOMETRY-D-0..31，1000年，与随机牛顿和冻结Q1候选配对。

figure-eight常用无量纲初值：(±.97000436,∓.24308753)，第三星在原点；两星速度(.466203685,.43236573)，第三星速度其-2倍。位置尺度1.6、速度按sqrt(GM/1.6)缩放。
已知几何本身不是寿命预筛选，但属于针对轨道族的设计，外推到任意随机混沌星系的可信度必须独立说明。

注意：periodic-control标签指没有行星时的三体周期初值；实际实验保留行星的完整引力反作用，四体运动可能破坏周期性，不能仅凭初值名称断言结果规则或混沌。
