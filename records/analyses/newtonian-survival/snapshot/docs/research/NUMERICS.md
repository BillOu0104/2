# 数值控制结果

24连续种子 ×11配置 ×400显示年 =264条，无资源中断。

原随机、精确牛顿力的默认固定步长有极端失败：总能量最大相对误差可达227；减半步长的另一个近遇路径甚至达754，因此只看中位数或只减半一次不够。
这些最大值包含行星已经损失或恒星接触后的点质量继续积分，不能直接解释为首次行星逃逸原因。
局部自适应eta=.03将最差误差降至1.23e-4，eta=.0075降至4.67e-7，中位数7.62e-10；后续独立确认采用更严格eta=.0075。
Q1.4圆轨道组eta=.0075最差误差3.92e-8；固定步长最差2.59。独立velocity-Verlet更保守小步长的主要生存指标一致，能量精度低于四阶实现。

关键：随机行星的固定、半步长、自适应.03、自适应.0075四组，24个种子的期末存活判定完全相同；受限寿命最大差仅1帧(1/60显示年)。因此这组有限窗口损失主要不是可由数值修复消除的现象。
原分段力减至四分之一步长后，对应势能误差中位数从4.04%降至.91%，仍远大于精确牛顿组，且期末幸存仍3/24。不能把分段增力当作普通牛顿参数。

## 真实引力能量交换

阶段1完成后选两个已发生逃逸的案例做机制诊断，而非筛选主组种子。案例 EXPLORE-A-3 和 -15 在诊断70显示年内无吞噬/恒星接触。
独立核算惯性四体质心系中行星比能变化，满足：

`d(vp²/2 - sum(G Mi / ri))/dt = sum(G Mi (ri-rp) dot vi / |ri-rp|³)`。

- A-3：行星比能 -0.16712 -> +0.02039，增量.18751；恒星运动做功积分吻合，绝对残差2.63e-11，总能相对误差2.23e-13。
- A-15：-.10925 -> +.12875，增量.23800；残差5.63e-12，总能误差1.08e-13。

证据表明即使整个系统能量守恒、行星最初负能，移动恒星的时变引力场仍可把它变为正能，这是实际牛顿能量交换/引力弹弓。
不能从这些诊断案例推导事件的总体发生率；总体发生率只用未筛选队列。
