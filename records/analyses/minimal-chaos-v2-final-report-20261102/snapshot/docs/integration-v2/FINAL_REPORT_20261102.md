# 三星壁纸 V2 长期研究最终报告

结案日期：2026-11-02（北京时间）。状态：**CLOSED_BY_USER_PARTIAL_H8**。
用户决定放弃剩余 h8 复测，按现有证据结束研究；不再自动恢复剩余批次。此为研究工作结案，不表示原 h8 全128匹配协议完成、数值收敛通过或正式产品验收通过。旧实验和失败证据全部保留，不删除数据，不修改计算源码，不合并 main，不发布网页。

## 1. 最终结论与选择

事件型近遇保护加弱束缚捕获，在已经完成的原生与 JS 独立随机确认中，显著改善了三星长期完整性，同时保留大多数样本的有限窗混沌联合证据。JS 正式确认的两个候选均有128/128个初值保持三星完整至100000显示年；转向和反射分别118/128、124/128通过严格联合混沌门槛。完整存活不等于所有样本持续满足混沌，更不等于原行星或原文明存活。

若需要从现有两方案选取壁纸原型，**转向+弱束缚捕获是较低累计控制成本、较高恒纪元占比的优先折中候选**；反射+捕获保留为联合混沌通过率和净角动量偏移方面的对照。两者互不支配，均未证明绝对最小干预，当前研究不授权覆盖 main 或直接宣告真实 Wallpaper Engine 宿主验收通过。

剩余24/128个h8匹配Seed（18.75%）没有进入本次统计，无法断言其影响很小。全128配对精度评审未完成；104例的描述性点估计不能替代原固定置信区间判据。

机制针对近遇真实半径接触和能量交换造成的外逸：转向预判危险近心距并改变相对速度方向，极端情况反射兜底；捕获仅在外逸危险时降低第三星相对能量并重分配动能。真实碰撞半径、独立逃逸判据与三星时钟不变。没有脚本周期轨道、寿命预筛或整宇宙重置。

## 6. 混沌、最小干预及行星边界

联合诊断要求三星完整、成熟条件FTLE>0.003/年、最紧束缚星对交换≥20、最长动态层级<1000年、最长几何隔离≤5000年及成熟非层级占比≥0.1。它提供有限窗条件恒星影子与持续相互作用证据，不是完整四体无限时间Lyapunov谱或数学混沌证明。

控制是瞬时速度脉冲。低激活帧占比和接近零的有符号净功不能代表低累计人工作用；绝对功、冲量、角动量及速度跳变必须一起评估。无指定脉冲持续时间，有限峰值/平均加速度无定义。转向成本较低但净L偏移和部分混沌不足更突出；反射成本明显更高。

P5会在真实行星损失后至少5显示年按冻结规则重生，记录能量、P/L及生命周期；三星时钟不重置，缺席时恒纪元计0。长期恒纪元依赖行星续生，不代表原行星或文明受保护。P5 impulse字段是动量模长变化的累计，**不是完整矢量跳变冲量**；旧值保留，完整矢量成本仍未验证，不混入修复。
