# 加严逃逸与第二批候选（strict-screen前）

screen-v3漏报原因：产品七个四体二分簇要求每一侧都紧致；如果无束缚行星与一颗恒星分别远离，任一侧可能都不是紧致簇，真实恒星瓦解反而被漏掉。例如V2-A-3无控制在1000年已有恒星离原点78单位。保留全部旧行，但其“stellarIntact”不得用于最终结论。

统一加严：恒星独立三体子系统，枚举一星/其余两星。星距恒星质心>6，簇间距>4倍双星簇半径，向外，相对比动能与实际跨簇势所构成的能量>势绝对值10%，连续3年即瓦解。行星不会阻止恒星逃逸识别。另查三星全体两两正能、向外且三星总内能正且有星越界的持续3年分散。原有四体判据继续用于行星独立逃逸。所有新配置统一使用此规则，不放宽已有阈值。是项目模型内的保守操作定义，不宣称数学证明永久无返回。

新增候选：

- reflect：仅当两星向内穿越1.15×最大呼吸半径之和时，反射相对径向速度。保持质量、位置、总能量、总动量和总角动量，改变轨迹；强脉冲须如实计成本。正常近遇及普通弹弓保留，不能称无干预。
- reflect-cap：仅接触保护加原外逸速度上界反馈。
- reflect-transfer：把外逸速度上界反馈移除的动能，通过其余两星的径向相对速度增量全部返还。目标是不因持续耗散走向规则吸引子；总做功近零不代表轨迹/冲量成本低。全部正负能量转移与脉冲计账。
- narrow-cap：将斥势激活半径从.25降至.12，alpha提高到4；检验更窄但更强的危险区是否减少累计干预。

全部继续用预定随机生成器、相同P5和V2-A-0..15，1000年；这是探索集，不是独立确认。选择前不运行正式确认前缀。
