# 确认后数值敏感性扩展，2026-10-22

本方案在看到576条完整确认结果及32对精度结果之后制定，是诊断性扩展，不是新的独立确认，不改变CONFIRMATION_PROTOCOL及其主组/阈值/参数。主确认128Seed结果永久保留，不选择细精度中表现更好的轨迹替代主组。

触发原因：默认精度对比预定前32Seed的h2，成熟恒纪元均值转向24.247%→34.578%，反射23.691%→14.385%。配对Seed bootstrap差值区间未包含0（详见cohort.review.json）。有限样本与长期混沌的统计敏感性尚不能排除。能量残差小不能据此宣称恒纪元统计收敛。

固定扩展：

- 第一阶段：确认Seed32..127，两候选参数完全不变，dt=.000375、eta=.00375，补齐各128个h2；192条新模拟。结合先前预定0..31辅助组，明确其原配置和来源，组成数值比较队列，不增加主确认独立Seed数。
- 第二阶段：确认Seed0..31，两候选dt=.0001875、eta=.001875，各32个h4，共64条新模拟。先前32个h2均保留，进行匹配的default/h2/h4比较。
- 所有新模拟都真正积分100000显示年、45000求解器单位；成熟窗口固定10000年后；行星P5、半径、失效规则、条件影子、控制和纪元阈值均不改。最大步长减小，不提高时钟速度。每条h2至少1.2亿、h4至少2.4亿名义步。
- 不改变或优化物理计算源7f64a8a及二进制。沿用冻结流式传输、状态恢复和逐结果哈希审计。两worker，总共2CPU，不购买资源。
- 8Seed一批，12批h2后4批h4；256条新结果。每批记录失败/UNKNOWN、所有行星重生和控制预算，提交Git/records并尝试推送。任何UNKNOWN、哈希或原始初值不匹配即停止升级。主组真实失败不被重置，完成键不重复统计。
- 输出成对差值及Seed bootstrap区间、混沌联合率及其分布、控制成本、行星损失、采样数值残差。bootstrap固定20000次、随机种子20261022。展示完整分布，不因某个Seed敏感而删除。若差异仍未厘清，继续明确标注未收敛，不能自动进入正式替换。

本扩展没有预先规定统计等价界限，不能凭未显著差异证明等价；事后指定等价区间只能作探索性敏感性分析。以128个h2/32个h4运行完毕为本批完成，不代表整个V2研究结束。还需数值评审、最小干预权衡及完整正式壁纸集成/回归/UI兼容性。main最终替换依然等待用户验收。
