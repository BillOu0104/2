# 成熟阶段稳健性、消融与100000年探索预注册

依据WEAK30_RESULTS.md，保留两个方向：反射触发8较少改变角动量，但峰值跳变和累计绝对功较高；预测转向4+触发8成本更低、混沌诊断更好，但改变角动量。触发24保留为100000年宽触发间隔对照。现在不选定唯一最优，也不接触正式确认集。

计算源冻结7f64a8a，生产代码不变。最大步长.00075、eta .0075为主实验，只有数值敏感性组将两者减半，绝不增大步长加速。初始化、真实半径、逃逸/接触失败判据、纪元阈值、P5及成本账不变；消融中的初始化和不重生单独标记。

顺序和固定样本：

1. precision30k：V2-D-0..7，两个候选，各将最大步长/eta减半到.000375/.00375，30000年，共16条。与已完成weak30k中的同Seed默认精度组匹配比较。混沌长窗不要求不同精度轨迹逐位重合；比较失败、恒纪元、混沌、控制成本及扣除外部预算的数值残差，报告8Seed证据限制。相同代码与配置检查点恢复另有逐位验证。
2. shadow30k：V2-D-0..3，两个候选，各用(eps,窗口年)=(1e-7,10)、(1e-9,10)、(1e-8,5)、(1e-8,20)，30000年，共32条。与默认1e-8/10年匹配。要求主轨迹最终状态、步数、恒纪元、控制账和行星/文明计数逐位相同；否则指标影响物理主轨迹，停止后续阶段。FTLE原始分布和诊断翻转都报告，不能挑幅度提高分数。
3. ablation30k：V2-ABLATION-0..7新探索种子，初始化research/chaotic × newton/deflect4-trigger8 × P5/noRespawn，共64条，30000年。固定全窗口分母；行星消失后无重生组恒纪元记0。无长寿预筛，不删立即失败；用相同初始化的控制对照分开评估初始化与控制贡献。不同初始化之间不要求初值相同。
4. explore100k：V2-E-0..15新探索种子，无控制、原牢笼、反射触发8、反射触发24、转向4触发8，共80条，真正100000显示年。它是正式确认前的长窗探索，不是128Seed确认，也不把短窗结果或不同Seed拼接成100000年。成熟窗口仍[10000,100000]。

这些Seed都属于探索/诊断，不能进入V2-CONFIRM-20261021。正式确认至少128新Seed仍封存，候选冻结后再用独立配置实测，不能在看到确认结果后继续调参却保留确认名义。

每阶段两Shard、最多2个CPU worker；全部原始结果、失败、数值UNKNOWN、行星/文明和预算保留。只有完整哈希审计通过且数值UNKNOWN为0才自动进入下一阶段；真实物理失败是结果，不能据此筛Seed。影子组额外要求主轨迹不受测量参数影响。统计诊断差异可继续探索100000年，但不自动证明收敛、不自动冻结最优、不自动运行正式确认或集成main。出现数值/哈希/主轨迹不一致则停止并记录待分析原因。

run-series.py只编排既有原生求解器和已注册配置，不重编译、不改计算源。它保存全局锁、阶段状态、逐Seed检查点、源码/配置/二进制与驱动哈希。阶段结束提交数据、capture记录、check并推送研究分支；推送受网络失败影响时记录并继续本地研究，不把未推送说成已推送。重启同一命令校验哈希并跳过完成键；先遵守STATUS的20分钟/活跃worker去重检查。
