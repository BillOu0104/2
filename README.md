# 三体 · 实时演算

当前版本 **v0.4.0**，已合并前次v0.3本地修订。新增右侧运行统计与双排行、紧凑时钟日志、速度受限的视角惯性；见 [docs/V04-UPDATE.md](docs/V04-UPDATE.md)。

基于用户提供的 Wallpaper Engine《三体实时演算》Scene 工程移植。原场景作者 SYKM，音乐 Melodysheep · Ether。此工程保留原资源来源及随附非商用说明。

## 运行

```sh
npm ci
npm run dev
```

打开 `http://localhost:4173`。`npm run build` 生成完整离线网页到 `dist/`；`npm start` 使用已有构建。没有 CDN、外部字体、远程 API 或必须运行的远程后端。

### Wallpaper Engine

1. 解压交付的 `three-body-wallpaper.zip` 到独立文件夹。
2. Wallpaper Engine → 创建壁纸 → 打开该文件夹的 `index.html`，选择 Web 类型。
3. 工程包含 `project.json`，保留原版183个用户属性及其原始键名。原生属性修改会同步右下角面板；面板内的修改在该壁纸浏览器存储中保存。
4. 点击右下角齿轮打开设置，点击同一按钮或面板内 × 关闭。画面拖动/鼠标跟随由“视角模式”决定。
5. 建议先使用默认设置。硬件较弱时降低“最大渲染像素比”，或关闭“超后处理”、尘埃、星芒。

普通网页请通过 HTTP 服务访问。WE 的 CEF 本地文件宿主使用打包资源及 Blob Worker；本环境的浏览器管理策略阻止 `file://` 导航，不能在此验证本地文件入口。当前环境没有 Windows 和 Wallpaper Engine 程序，因此**尚未进行真实 WE 宿主验收**；已验证其属性、音频、暂停回调适配。

## 已实现

- 原版四体 Yoshida 1990 四阶辛积分、原分段软化、软/硬引力牢笼、随机初始位置/速度、自定义四体初值、逃逸与重启。
- 原版辐射平衡温度、冰雪反照率和温度振荡，加上热惯性；纪元由轨道稳定性独立判断，天象、行星结构与文明状态分层处理。
- 文明在 −20～40°C 常态活动，脱水、干仓休眠与原编号复苏；干仓有限耐受、差分潮汐损伤及不可逆行星吞噬/撕裂，最近日志和延续排行；原版即时判定可切换保留。
- Three.js 场景、原版背景/太阳/行星纹理、圆形天体与柔光、默认开启的四组渐隐尾迹、导航圆环、主题色、镜头模式、时钟和各 UI 布局设置。背景、星云、尘埃与天体共享视角旋转。
- 原版183个可操作属性，按原分组搜索与修改；另有14个运行设置。原版标注“固定”的引力指数保持2，界面明确禁用。
- 累计运行年数、当前宇宙与文明的编号和寿命；文明和宇宙各前五名，包含仍在运行的条目，本地保存。
- 自定义背景本地持久化、音乐主动播放和音量、WE系统音频、暂停恢复、全屏。
- 新增确定性 Seed、参数导入导出、本地 IndexedDB 文明档案和死亡时初值记录。原版“文明种子”手动初值模式完整保留。

## 兼容策略和边界

原脚本不是网页 JavaScript，存在 `engine/shared/Vec3/createScriptProperties` 等 WE 专属依赖。`src/legacy/`保留可读业务源码，通过局部兼容上下文运行，既不对整个附件求值，也不执行附件说明中的命令。

**默认 reference 物理模式**：模拟固定60 Hz，每个参考帧按原版最多10个物理子步，默认步长0.75ms。原版时间倍速的平方效应、原分段软化的不连续处均保留。渲染帧率不再改变模拟结果。可选 realtime 模式补足墙钟时间预算；它产生不同轨迹，应与 reference 分开比较。

**0.3 原著讲解优化**：默认 `balanced` 模式分开纪元、天象、行星和文明状态。恒纪元依据暂时束缚与主导恒星扰动判断，不再等同适温；乱纪元也能保存文明。常态活动默认 −20～40°C，离开适温/安全窗口后脱水休眠，安全后复苏同一编号。干仓耐受有限，持续极端气候会毁灭；三日连珠与飞星不是自动灭绝条件。差分引力张量累计行星结构损伤，吞噬或大撕裂后锁定终态，直到重建宇宙才恢复。具体模型、参数和未实现的现象见 [docs/REFERENCE-MODEL.md](docs/REFERENCE-MODEL.md)。数值阈值为项目模型，不声称由小说直接给定。

六项暂存反馈均已实现：仅拖动时显示旋转环；静置默认 0.35°/秒；文明信息紧凑排列、日志统一字号并逐渐淡出；常态活动范围 −20～40°C；删除两侧顶部文字和 YEARS 下说明。旧版本配置自动迁移，文明档案保留。

默认尾迹改为开启；从v1迁移时首次开启，后续明确关闭的偏好会保存。尾迹长度基准20–2000，按屏幕弧长、转弯与重叠情况自适应；单调缓慢运动保留更长历史，复杂快速运动缩短显示并减弱亮度，最多保留120秒历史、每条最多1999个GPU线段。四种颜色可配置；切换尾迹和颜色不会重置物理。圆形光晕取代原星芒贴片，渐隐线使用屏幕宽度渲染。

必要修复：更改步长会立即重建积分器；六组天体距离集中计算，修复原版恒星碰撞距离未赋值；温度只由079脚本提供，消除旧HUD脚本覆盖；后台暂停时不累积长时间追赶；时间因子保留平方效应，但切换倍速只影响后续年数，修复已运行年份被追溯缩放；移植重启不会再触发原版120帧后的二次初始化。重启过渡缩短为约2秒，先完成一次实际初始化，再播放视觉遮罩。

Three.js 使用球体和圆环重建 `.mdl` 几何；纹理来自原 `.tex` 首 mip。三个背景纹理已恢复为原生8192×4096转换副本（未上采样），太阳/行星纹理保留原始尺寸。默认按屏幕像素密度渲染，可在设置中选择最高7680×4320的8K超采样，受GPU上限约束；已验证实际8K帧缓冲和后处理绘制。HDR辉光使用径向圆形贴片，强度和散射分别控制透明度与半径，避免小天体在降采样Bloom中出现方形光斑。光效/CRT/模糊/脉冲/颗粒为浏览器后处理近似，登录/加载界面和部分装饰重新实现，因此不能声称逐像素或逐帧完全一致。原版没有人口、科技树或真实物理碰撞合并；本项目也没有将这些当作已还原功能。

档案保留初始化四体参数、当次设置、死因和寿命。点击复现使用当时的初始位置和速度；运行中变更参数和温度正弦的全局相位尚未作为完整回放时间线记录。v0.4排行榜和累计年数通过本地检查点跨刷新保留；刷新会结束上一段运行、开启下一编号宇宙。旧版文明档案可用于初始化文明排行，旧版没有完整宇宙计时记录，宇宙累计统计从v0.4开始。未连接线上Seed榜。

完整来源、公式、默认值、原版缺陷和183项清单见 [docs/SOURCE-AUDIT.md](docs/SOURCE-AUDIT.md)，引擎原始属性绑定见 [docs/scene-bindings.json](docs/scene-bindings.json)。

## 架构与扩展

```text
原版属性 Schema → 设置校验/本地存储 → Worker 消息
                                           ↓
                                Simulation（纯 JS 后端）
                                  原版物理/温度 + 纪元/天象/行星/文明状态机
                                           ↓
                       30 Hz 状态快照 + 结构化领域事件
                          ↙                         ↘
                 Three.js + HUD                 IndexedDB 档案
```

模拟内核 `src/simulation.js` 无 DOM 或 WebGL 依赖，可直接在 Node 中运行。默认后台使用 Web Worker，满足独立网页与离线壁纸，也为以后替换 Node 服务或远程计算保留边界。未引入远程常驻服务器，因为当前模拟只有四个天体，离线运行更适合壁纸。

`window.threeBody.getState()` 返回当前快照，`applySettings(patch)` 更新设置；`subscribe(type, listener)` 订阅领域事件，并返回取消订阅函数。可用事件为 `civilization:birth`、`civilization:death`、`system:escape`、`civilization:phase`、`planet:damaged`、`planet:destroyed`、`universe:restart`。未来系统通知、文明历史记忆、Seed榜可通过这些边界接入，通知功能当前没有申请任何系统权限。

适配 `wallpaperPropertyListener.applyUserProperties`、`applyGeneralProperties`、`setPaused`、`wallpaperRegisterAudioListener`。普通网页音频使用 Web Audio，须主动打开播放；不会把伪造的随机频谱作为真实音频响应。
