# 弱负能触发间隔反馈预注册

在查看V2-D数据前，依据V2-C-2/C-4长远游证据注册。固定初始生成规则、质量、半径、积分步长、eta、P5行星协议、恒纪元判据和分母；无寿命预筛。旧算法全部保留。

唯一新控制参数captureTriggerScale=S：对已满足旧向外速度、R>1.5初始尺度、R>1.5另一对间距的星，当Jacobi epsilon>-GM/(S*初始尺度)时纠正到旧目标-GM/(4*初始尺度)。S=8/24，与正能触发对照。径向反作用和能量转移方式完全沿用，无法仅用径向速度纠正时的切向缩放仍计入角动量代价。没有时间积分或步长放宽。

该间隔避免连续钳制在目标附近逐帧重复投影，同时预期截断极弱负能长周期远游；可能副作用是额外激活、内双星加热/紧缩、碰撞保护频繁化和混沌退化。总能量与动量近零变化不代表零成本，累计绝对功、冲量、峰值速度跳变必须报告。

V2-D-0..15连续新探索种子，六方案：无控制、旧牢笼（均加影子测量但不改变主轨迹）、旧positive-transfer、reflect-trigger8、reflect-trigger24、deflect4-trigger8。先1000，10000，再30000显示年。各窗口重新以同规则初值运行，不把不同horizon的结果累加成一段长窗；用于功能及中长期比较，不独立重复统计同Seed。任何错误停止升级并保存UNKNOWN，不悄悄排除失败。

成熟期固定10000年后。已冻结的正式联合诊断为成熟FTLE>0.003/年、成熟紧双星身份交换>=20、最长连续动力学层级<1000年；30k探索按同等交换率要求>=5。持续束缚不代表持续参与，另报远游/非层级时间和分段指标。
