# 从反射保护到预测转向的下一阶段假设

注册时点：medium-canonical尚在运行，尚未使用V2-C或正式确认种子。以下为候选，不预定胜者。

中期已见的风险是持续能量上界投影会导致紧双星/层级化，以及反射虽极稀疏但单次速度改变量大。对照方向：在碰撞危险尚未到达实体接触保护半径时，能否以更小的速度转角避免接触，保留普通弹弓。

拟采用两体瞬时近心距预测：r、u为一对星相对位置/速度，mu=G(mi+mj)，epsilon=|u|²/2−mu/r，h=|r×u|，e=sqrt(1+2epsilon h²/mu²)，q=h²/[mu(1+e)]。只在向内、r小于4倍或8倍最大呼吸物理半径之和、q小于1.15倍该半径和时启动。

目标q*=1.30倍最大半径和，所需切向速度平方 vt*²=[2 q*² epsilon+2 mu q*]/r²。保持总相对速率，尽量沿原切向方向转向，新的径向速度保持向内。两颗星按质量反冲，位置不动，动能及总动量保持；角动量会改变，必须累计记录，不能宣称无代价。目标缓冲用于减少同一次近遇的连续微调。若预测受到第三星干扰或已太接近，则保留原反射保护作为显式记录的后备。

优先与同一positive-only外逸/内部能量返还控制匹配比较。若更低冲量换来长期角动量漂移、规则化、碰撞或无法维持恒纪元，应如实保留失败结果，而非只看短期代价下降。
