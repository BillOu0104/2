# 首轮候选与行星协议（首批积分前）

初轮不假定最优：none、原软牢笼、近碰撞中央斥势、外逸能量反馈、后两者组合。近碰撞势在r>=r0严格为零；r0暂取.25，Ucontrol=Gmimj/r×alpha×(r0/r−1)^4，alpha=.1，只作用恒星对。正常牛顿项完整保留。斥势的梯度与势能单独记录，仍须排除碰撞并检验数值误差。

外逸反馈作用于一星/其余两星质心的Jacobi相对运动；当向外、距离>初始平均星距的1.5倍、相对比能高于−G M/(4×初始平均星距)时，将径向速度降低到该能量界面。若切向动能本身已超界则整体缩放相对速度。反冲分配给其余两星，位置不变，保持三星总动量；径向修正保持总角动量，整体缩放所改变量纳入预算。这是人工速度投影，不宣称纯牛顿、无功或微弱。需要根据累计成本和规则化结果决定是否保留。
