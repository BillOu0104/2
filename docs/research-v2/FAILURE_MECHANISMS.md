# 基准失败机制：现有证据和限制

来源：计算源bf7f9d2、long30.json，V2-C匹配16种子，最长30000显示年。全部失败和原始事件保留；行星P5协议与恒星完整性分开。以下是探索性描述，不能推广为所有随机初值下的精确风险。

|基准|真实恒星接触|动力学确认分离|完整运行|积分终点年数中位数|
|---|---:|---:|---:|---:|
|无控制|14|1|1|526.74|
|原软牢笼|16|0|0|401.47|

终点包含成功窗口和提前失败，表中不是右删失寿命估计。接触前最后接受态的相对速度中位数分别2.331、2.387（求解器单位），范围分别2.191–2.564、2.177–2.657；不是插值到接触瞬间的精确速度。样本不足以仅凭这两组速度证明牢笼必然加速每一次碰撞。

原软牢笼主要响应距整体质心的半径，不能直接识别两星的低角动量碰撞近心距，也不区分向内/向外运动、星对相对能量或分离簇。因而它能提供回拉，却没有真实物理半径接触保护。本批仍全部接触失败，未表现出三星完整率改善。不能把“没有观测到逃逸”当作有效长期稳定，因为更早的碰撞已终止观察。

受控对照将风险拆开：仅反射在10000年也只有7/32完整；反射加外逸反馈达32/32，说明消除碰撞后仍须关注分离。本批四联合30k均16/16完整，但只对正能外逸纠正会漏掉近抛物的弱负能远游。C-4约6.85万显示年的外轨道周期说明“束缚”与“持续参与同一混沌系统”不能等同。

反馈副作用同样有实测证据：持续cap高累计干预并易出现动力学层级；反射保能量和角动量却可有强瞬时速度反转；提前近心距转向显著减小速度改变量和累计绝对功，却改变角动量且仍可长远游。新触发间隔反馈针对上述机制测试，不预先宣称最优。

仍缺：更大样本逃逸前的逐近遇能量/角动量时序、受控事件步长收敛、100000年正式确认、完整四体混沌敏感性及生产UI兼容性。当前条件影子FTLE和轨道几何仅为互补证据，不是视觉判断，也不是无限时间混沌证明。
