## 正式行为

- 默认 `deflect-v2`，保护默认开启。正常段采用无软化牛顿平方反比力；Yoshida 四阶、近遇自适应和接受步前控制顺序不变。h4 最大子步 **0.0001875**、η **0.001875**；每帧推进0.0075求解单位、60帧/显示年。
- 危险近遇转向保持配对相对速度模长、包含质量反冲；外逸弱束缚捕获将移出的能量再分配给另外两颗恒星。保留已验证实现中的极近遇反射兜底。它属于 deflect-v2 的内部路径，不能任意删除后仍宣称采用相同算法。
- 这是明确的人工速度控制，不是纯牛顿自治系统。控制事件逐次记录速度改变量、功、冲量及 P/L。净功接近0不表示没有干预；无脉冲持续时间时，有限峰值加速度没有定义。
- P5：真实吞噬、潮汐毁灭或确认逃逸后移除行星，至少等待5显示年，再按既有宿主轮换、局部逆向轨道和黄金角相位生成新行星。三星和宇宙计时继续，旧文明死亡保留，新行星重新发展文明；不把重生当作同一行星或文明长寿。
- 恒星碰撞/确认分离是吸收失效，停止并提供手动新宇宙入口。V2 忽略旧自动整宇宙重启开关，不用重置、隐藏灾难或改恒纪元阈值提高成绩。数值失败单独显示错误/UNKNOWN，并暂停等待修正。
- 文明、韧性、科技等级、纪元和气候算法文件均沿用 v0.5.5。没有调整活动温度、韧性、恒纪元时间窗、逃逸距离或潮汐阈值；任意自定义参数不继承预注册默认参数的研究成绩。
- Seed、随机初始化和自定义四体初值仍由原初始化器处理。V2 初始化时禁用旧牢笼预处理，避免混入两套控制；新控制器通过原保护开关控制。自定义初值不会被自动轨道覆盖。

## 兼容与缺陷修复

1. 设置只暴露“V2转向”与“旧版牛顿/牢笼”。旧安装升级默认采用 V2，同时备份原物理配置；切回旧版恢复原模式/步长/η/时钟/牢笼。显式选择旧版保持旧版。旧 Seed 档案按旧算法重放；研究专用反射配置明确报错，提示回研究分支，不静默替换算法。
2. V2 不支持的旧物理参数保留但置灰，避免显示可改却无效。新增0.25–4倍播放速度，用完整模拟帧排队调度，不增大子步、不跳过物理时间。Worker 每次调度有墙钟预算，未执行的完整帧保留待处理。
3. 行星缺席期间不显示假温度/适居度/发展状态，不判恒纪元；隐藏行星、标签和尾迹，重生后断开旧轨迹。恒星尾迹继续。保留 v0.5.5 连续带状轨迹、前景粒子、8K素材、相机交互、银河回归、时钟、通知、菜单和布局。
4. 修复同一帧行星死亡随后恒星失效导致文明死亡档案遗漏；P5事件使用真实显示年；失败原因保持吞噬/潮汐/逃逸区分。
5. 修复模式切换时新算法标题与旧物理快照混合发布：状态标记 initializing，Worker 只发布完整已接受帧；发生数值错误仍发布明确错误。修正设置后可恢复失败的 Worker，原暂停状态独立保留。
6. 修复浏览器步长滑条把0.1875四舍五入到0.188的问题；精度输入与实际固定h4一致。
7. P5历史 `external.impulse` 是动量模长变化累计。保留其原值，另加 `planetExternal.vectorImpulse` 记录实际矢量动量跳变的范数累计。旧检查点缺失此字段时标记 `vectorImpulseComplete=false`，不假称历史预算完整；不改写研究结果。
8. 默认仍以初始质心为固定显示原点，镜头位置不跟随。P5移除/加入质量和动量是真实外部事件，长期可使系统离开初始画面；新增显式可选“全系统质心”显示参考系，统一平移天体与轨迹。它不改变物理坐标或镜头方向，也不追踪最近恒星对。切回固定原点即时生效，包括动画暂停时。
9. 已运行时切换算法或修改物理初值，结算旧配置的宇宙并留下 settings 原因；普通显示、保护开关和播放速度变动不重建宇宙。检查点保留物理、文明、世界、RNG及追踪状态；浏览器正常刷新仍沿用已有“结算并新开宇宙”的行为，不额外引入自动断点续跑。

## 数值研究状态与剩余限制

读取 JS_CONFIRMATION_RESULTS：h4的128个独立匹配初值中，转向三星完整128/128，严格混沌联合118/128，成熟恒纪元均值33.99%；**10例混沌不足保留**，不保证每个Seed持续混沌。原始行星仅1/128存活、原始文明0/128，长寿系统结果依赖P5。转向累计绝对控制功均值47.42倍初始能量，不能称绝对最小干预。

截至 `results/h8-remote-status.json` 对应远端版本，h8目标256端点/64个100000年结局，只看到**13个端点，其中2个100000年结局**。没有最终配对置信区间与精度验收报告。采用原验证h4，**没有降低精度，也没有将未完成h8判为通过**。保持研究预定的±5个百分点配对区间门槛，不重启队列、不修改冻结结果。较小能量余额残差不能证明长期统计收敛；长时间混沌轨迹也不保证跨JS引擎逐位相同。

真实 Windows Wallpaper Engine 宿主未提供；已验证离线构建、Chromium桥接/暂停/Worker/UI，仍需宿主实际验收。任意极端自定义初值可能触发真实物理失效或数值暂停，不强行维持轨道。固定显示原点的长时漂移属于P5外部动量的已知后果；可选参考系只解决显示，不宣称消除了物理动量变化。
