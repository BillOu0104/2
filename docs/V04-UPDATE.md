# v0.4.0

合并此前未发布的v0.3修订：默认隐藏天体旁字母，修正即时适宜度与损伤风险，结构受损可提前切换下一宇宙，删除活动温区小字，尾迹随运动与复杂度自适应。

本版新增：

- 时钟上移约3%屏幕高度，星期/日期位于时间下缘2px处，使用相同字号。
- 中央日志统一9.5px、小屏9px，压缩间距，显示最近10条，保留12条原始事件，按时间渐隐。
- 右侧改为基础信息，展示累计年数、当前宇宙编号/运行年数、当前文明编号/延续年数。
- 文明延续与宇宙寿命各显示5名，降序排序；正在运行的条目满足名次时实时参与，并标明进行中。
- 统计本地保存，刷新结算上一段运行并开启下一编号宇宙。旧版文明档案保留并用于初始化文明榜；旧版没有完整宇宙计时，宇宙统计从v0.4起记录。
- 时间倍速仍保留原版平方效应，但只影响后续累计速率，切换倍速不使年份回退或追溯跳变。
- 加强转动响应与阻力，合成角速度限制为0.55rad/s。跟随模式加速度上限4rad/s²；低帧率时也按实际时间衰减惯性。
- 删除底部音频柱形成的虚线，保留系统音频适配与星体响应。

验证报告见 `docs/qa/v04-simulation-report.txt`、`v04-browser-report.json`、`browser-report.json`、`state-ui-8k-report.json` 与 `tail-render-report.json`。8K帧缓冲和后处理绘制已通过浏览器验证；当前环境不含Windows Wallpaper Engine，实机与目标GPU帧率验收仍需该宿主。
