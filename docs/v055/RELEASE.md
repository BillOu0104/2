# v0.5.5：固定显示原点、直接守恒核查与连续尾迹

比较基线：`472a7ee`（v0.5.4及其静态复核记录）。独立验收分支 `fix/v0.5.5`，不覆盖main。预览继续使用原私有网页。

## 先核查动力学，再修改显示

本次先检查实际v0.5.4生产代码，随后在修改后的版本用相同条件对照：4个事先确定的Seed，各1000显示年；research随机三星、牛顿引力、关闭牢笼与自动重建。每帧从四体原始坐标、速度、质量独立计算固定惯性系能量、总动量，以及总质心相对理论位置 `R₀+V₀t` 的偏差。不是比较两个版本自报的诊断值，也没有筛掉失败Seed。

| 指标 | v0.5.4 | v0.5.5 |
|---|---:|---:|
| 最大总质心位置偏差（模拟长度单位） | 4.945×10⁻¹² | 相同 |
| 最大归一化总动量偏差 | 2.965×10⁻¹³ | 相同 |
| 星体接触前最大相对惯性系能量误差 | 9.551×10⁻⁹ | 相同 |
| 包括接触后的最大相对能量误差 | 1.230×10⁻⁸ | 相同 |
| 匹配Seed在1000年的四体位置、速度、质量 | 基线 | 逐位相同 |

原始条件、每个Seed的数据、星体接触时间和数值中断栏见 `results/conservation-before.json`、`conservation-after.json`、`conservation-comparison.json`；复现脚本为 `tools/v055/conservation-audit.mjs`。这是一个有前后对照的针对性守恒实验，不是新一轮128种子存活率实验。

该样本没有复现“全体四体质心明显漂走”。例如Seed0到1000年时，双星约在(4,20,4)，另一颗恒星约在(-8,-40,-8)，行星也已远离，但全体总质心仍在原点约10⁻¹²附近。这符合真实动量反冲，不是靠镜头跟随维持的守恒。总质心不动，并不要求剩余双星不动。

**不将这一结果冒称为已发现并修复了某个能量注入缺陷。** 样本不能证明所有Seed和近遇都可靠；四个样本中三个发生星体接触，接触前后的误差分开保存。点质量模型在真实星体接触后本身有限制，当前碰撞路径没有因此变成真实流体合并模型。

## 镜头不再跟随星群或当前质心

删除 `display-center.js` 的星群/最近恒星对跟随。也停止每帧减去当前物理质心：每次宇宙或初态初始化时，只计算一次**初始四体质心**作为显示坐标原点，之后保持不动，天体组平移一直为零。

- 不追随双星，不随逃逸体改变中心，不平滑搬动镜头来掩盖偏移。
- 剩余星群真实反冲时可以离开画面；沿用v0.5.4确认逃逸后正常归档并开启下一号宇宙。
- 移除“自动居中星群”控件。旧`centerOnSystem`仅作导入兼容，归一化固定为false，不能重新开启跟随。界面现有217项控件。
- 默认research初值仍对四体整体去除初始位置和速度均值。自定义初值保留用户原始速度；如果输入总动量非零，系统会在固定画面中真实平移，不偷偷每帧清零。
- 鼠标悬停、拖动、惯性、旋转环以及闲置回归银河方向保留。这些是已有方向操作；本版移除的是自动追踪天体造成的观察中心平移。用户显式调整距离/视场角仍生效。

## 守恒诊断补齐

以前`energy`使用当前质心参考系下的内部动能。它适合判断内部轨道能量，却不能单独揭示全系统被错误施加相同速度的情况。

在不改变既有内部能量口径的基础上新增：

- `inertialKinetic`、`inertialEnergy`、`relativeInertialEnergyError`：固定惯性系动能、总能量与误差；内部和惯性系能量分别保留。
- `initialCenter`：初始质心位置及速度；`expectedCenter`：无外力时当前应在的位置。
- `centerPositionDrift`：实际总质心相对`R₀+V₀t`的偏差；`centerVelocityDrift`：总质心速度相对初始值的偏差。

项目说明的运行诊断新增ΔR和ΔVcm读数，仍保留ΔE、ΔP、ΔL与牢笼/接触标识。所有分量也可通过`window.threeBody.getState().physics`读取。牢笼开启时不将这些数据宣称为孤立系统守恒结果。

新测试故意给全部天体注入相同速度，验证内部能量可以不变，但新增惯性系能量与总动量/质心速度诊断会检出异常；另验证合法的非零初始总动量应产生匀速质心运动，不能误判为错误。

## 尾迹为何出现亮点与分段

旧的Line2将相邻线段各画一对圆形端帽，再采用加法混合。端帽重叠处亮度增加，所以每个接头都可能呈现一个小亮珠。旧轨迹还只在约30Hz Worker消息到达时取一点，尾迹几何约20Hz更新；高速时容易缺少中间转弯，尾迹头与单独平滑的天体位置也不完全一致。

本版改为：

1. 连续带状几何，相邻段共用边缘顶点，不在每段连接处堆圆帽；普通透明混合与边缘抗锯齿，尾端透明度渐隐，不以黑色线遮住背景。
2. Worker模式下从Yoshida积分器**实际接受的步进**复制位置，不额外推进模拟，不拟合另一套天体轨道。Node纯后端默认不开启该采样，提供独立参数用于测试。
3. 轨迹按位置和时间共同简化，误差目标0.0005模拟长度单位；初次预采样间距0.00025。保留加速直线的时间信息，避免几何是直线但插值速度错误。测试覆盖圆弧和变速直线。
4. 天体与尾迹头采用同一条真实采样轨迹、同一个显示时间。约50ms插值缓冲用于平滑两次Worker消息之间的显示，不外推；尾迹每个绘制帧更新。
5. 保留复杂场景缩短/简洁场景延长的自适应长度、颜色与尾迹开关。每体历史最多4096点，每尾最多1999段；传输每体最多512点，极端密集情况丢弃旧段时显式断开，不以一条直线跨接缺失轨迹。

自动化真实WebGL像素对比：同一条直线只改变中间连接点数量。旧画法的接头会产生亮度峰值；新画法从2点变成32点，中心线像素亮度保持一致，见`joints-before.png`、`joints-after.png`、`browser.json`。测试使用合成直线和手动紧凑快速轨道作为视觉夹具，**没有把默认随机三星改成稳定系统**。

## 验证与限制

- `node --test --test-isolation=none --test-reporter=spec tests/*.test.js`：124项回归；旧星群跟随的两项断言替换为固定参考系测试，历史归档保留原测试。
- 标准`npm test`及`npm run build`正常。
- Chromium实际Worker/WebGL验证：217控件与说明一致、旧跟随配置失效、非零初始总动量下镜头和显示原点固定、惯性系诊断、最大3倍速的紧凑快速轨道、尾迹头连接、开关、原有鼠标拖动/归位，以及接头像素对比。
- 物理步进开启/关闭轨迹采样的逐位一致性测试通过；本版不修正任何实际天体位置或速度。
- 保留初次浏览器验证日志：第一次夹具请求8倍速被既有最大3倍限制钳制，采样数假设不成立；改用合法3倍速的快速手动轨道。另有夹具favicon 404及固定700ms等待不足的失败；修正夹具图标，并等待实际显示位移后再断言，未降低位移阈值或修改产品物理参数。
- 软件WebGL验证，不代表所有GPU上性能完全相同；未在Windows原生Wallpaper Engine中实机验收。50ms是插值目标，低帧率/消息延迟时实际显示滞后可能更大。

算法标识升级为`v055-tech2-escape1`以标明诊断和显示版本；牛顿力、初值、引力牢笼参数、文明发展及逃逸确认条件不变。原私有网页与GitHub发布分别记录，见records/maintenance中的发布凭据。
