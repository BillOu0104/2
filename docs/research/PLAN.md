# 无牢笼三星行星研究：事前方案

研究基线：`c7a53a01def5f9d60389ee20ec0f8bac5210ed69`，分支 `research/newtonian-survival`。
只在 `docs/research/` 和 STATUS.md 写研究程序和记录，不修改运行产品。

## 不变约束

- 四体互相作用，牢笼关闭，不改变 G 的平方反比指数。原始分段力仅作历史比较。
- 种子编号事前连续生成，无寿命预筛选。探索集与后续验证集使用不同前缀。
- 原产品默认恒纪元定义：主星束缚、优势 >1.5、扰动 <.35，连续确认 1/12 显示年；原 WorldState 实现不变。
- 默认逃逸阈值 6；分开报告行星越界、系统任一天体越界、正能向外逃逸、吞噬、潮汐破坏。
- 全时窗恒纪元占比：首次行星损失之后计 0；同时报告存活时间，不能只对幸存片段归一化。
- 不以层级化、恒星逃逸后的一主星行星系统，冒充长期非层级混沌三星成功。
- 不将显示年误当 SI 年。默认每显示年推进 .45 求解器时间；减半步长时增加步数，保持物理时窗不变。

## 假设和次序

H1：随机全局速度未保证主星参考系束缚；仅修复行星圆/椭圆轨道可改善。
H2：原分段力不等于普通牛顿软化，近遇增力和边界跳变会影响散射和误差。
H3：恒星维里比与角动量影响近遇；高总负能不足以保证非层级三星长期紧致。
H4：较深的行星束缚与逆行可能抵抗潮汐/弹弓，但不能消除强近遇或宿主恒星逃逸。
H5：步长与近遇自适应控制误差；通过匹配种子统计和逐步收敛判断真正物理效应。
H6：尺度、质量和几何构型改变存活与动力学时标，必须同时报告维度时间和构型变化。

阶段 0：运行源码审计、旧求解器与研究驱动器一致性、二体守恒与收敛验证。
阶段 1：探索集多因素单变量比较，保存所有失败种子与原始指标，按效应而非单个成功轨迹选择后续。
阶段 2：根据阶段 1 写新假设后进行局部因素/数值收敛实验。
阶段 3：新的匹配种子验证主要候选，延长窗口并测试混沌敏感性与三星紧致性。
阶段 4：解释根因与误差，完整报告效果、区间、约束和有限时窗局限。

## 统计和恢复

每种子一条 JSONL，包含配置、初值、终态、停止原因、能量角动量误差、时序摘要及事件。
配对种子自助法 95% 区间，生存率 Wilson 区间；以种子而非时间采样点为独立单位。
扫描是探索性、多重比较，不用探索集置信区间冒充独立验证。
实验 manifest 保存程序哈希，逐种子追加并 fsync；重启跳过已有键，不重跑已完成试验。
每阶段提交 Git checkpoint。STATUS.md 写当前事实、假设和下一条命令。
平台不保证永久存活，阶段性结果优先落盘；未验证的持久化或调度能力不当作已配置。
