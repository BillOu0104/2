## 行星、文明及预算限制

转向/反射平均行星损失45.75/58.703次，原始行星仅1/128、2/128存活，原始文明均0/128。缺席均值0.22875%/0.29352%，全程缺席恒纪元记0；文明存在帧占比21.08%/15.34%，不等于同一文明存活。重生后固定25年贡献的成熟恒纪元仅0.823/1.126个百分点，但整个长期B仍依赖P5续生，不能声称原宜居行星被保护了100000年。
