# v0.5.3：显示居中、银河归位与慢速科技发展

用户澄清：“能量守恒”问题指天体离开画面中心；“自动回中”指回到银河背景，速度过快且有异常。本版按这两个实际症状修复，不把画面偏移当作能量不守恒的证据。

## 天体保持在显示中心

v0.5.2的显示原点固定在四体物理质心。行星即使质量小，飞得足够远仍会把质心拉离恒星群；一颗恒星弹射后也能让剩下的紧密星群偏离镜头。物理质心的定义没错，但它不总是合适的壁纸观察中心。

新增“视角与银河 → 自动居中星群”，默认开启：一般跟随恒星质量中心；三星最大/最小间距比超过4时跟随最近的恒星对。只平移天体和尾迹的渲染组，1.5秒时间常数平滑跟随；星空、导航环和物理数据各自保持坐标职责。关闭可恢复四体质心视图。此显示规则不是物理约束力，不能保证所有已远离的天体同时留在画面中。

**引力、Yoshida积分、随机初值、引力牢笼、纪元和行星损伤公式均未改变。** 不传送天体，不修正速度或能量。关于能量的项目说明区明确区分孤立系统、牢笼外力和星体接触后的模型限制。

8个预定匹配Seed、各200显示年、关闭自动重建，与实际v0.5.2生产代码比较：所有物理位置、速度、质量及能量/动量/角动量诊断逐位一致，未筛选种子。详见results/physical-parity.json。此测试不是重新声称千年/万年存活率提高；v0.5.2的真实长期弹射限制仍存在。

## 银河背景归位

- 修复惯性coast与returnToOrigin在同一帧互相竞争。无输入2秒后，归位独立接管并清除残余角速度；重新移动鼠标会打断归位，手动灵敏度和惯性参数保留。
- 默认从0.01降为**0.003°/秒**，约原默认的30%；限制的是总角速度，不再对两个轴各自完整施加速度。
- 按最近航向归位，不越过目标。固定视角模式不再被自动归位或残余惯性移动。静止指针的重复事件不应持续延后归位。
- 旋转环只响应近期手动运动；自动归位不把旋转环保持在屏幕上。尺寸、透明度及淡入/淡出参数保留。
- 旧默认0.01只迁移一次，已有自定义速度保留；迁移标识为galaxyReturnRevision=1。

## 十二阶段科技

从旧石器开始，保留“生产才积累、休眠保留但不积累、灭绝后新文明重新开始”的规则。默认倍率仍为1，数值表示累计安全生产年，非文明包含休眠的总寿命。终态和当前帧不安全时不再计科技进度。

旧版5生产年就升到农耕、350年到最高阶段；现在350生产年仍处于新石器阶段。阶段保护逐步增加，最高保护仍为原来的6倍韧性、±45°C活动温区扩展及±200°C干仓扩展，没有扩大顶级保护。发展倍率继续可调0.1–20，等级开关保留。

这是参考历史与原著发展方向的壁纸规则，不声称小说规定了这些阶段年数。旧档案的既有等级名与寿命保留，不篡改历史榜单；新文明使用technologyRevision=2。旧Seed的物理可重放，文明结果会因新科技规则发生变化。
